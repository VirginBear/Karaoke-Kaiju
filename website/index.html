核心能力

精心打造的音訊練習工具

結合專業 DSP 演算法與 macOS 風格的操作手感

±36 半音精準移調

嚴格遵循十二平均律標準，支援 ±6 至 ±36 半音微調，升降調與播放速度完全分離，男女轉換音域輕鬆自如。

Varispeed 磁帶連動

音高與速度以物理連動模式即時處理，避免額外時間拉伸；極端設定仍可能產生音質偽影。

Vocal Reducer 人聲消減

以中置聲道降低主唱人聲；效果依混音而異，並非完整 AI 分軌，仍可保留鼓與 Bass 的部分成分。

3 段等化器 (Equalizer)

低音 100Hz、中音 1kHz、高音 8kHz 獨立增益微調，內建人聲增強與重低音等多種實用預設。

多段 Loop 片段與循序練習

同一首歌可儲存多個命名循環片段（主歌、副歌、Solo），支援自訂階梯式提速訓練（0.75× → 0.90× → 1.0×）。

BPM 測速與節拍器

提供音訊自動偵測、Tap Tempo 手動測速與 4/4 拍視覺脈衝燈號；自動結果仍可手動微調。

純粹、專注，為音樂人而生。

我們相信好工具應該是順手、安靜且尊重使用者。「調唱」目前維持個人測試版、不放橫幅廣告；核心音訊在瀏覽器本機處理，AI 歌詞只有在你主動同意後才會送往 Groq。

本機優先 移調、變速與 BPM 透過 Web Audio 在瀏覽器處理；AI 歌詞是明確同意後的選用外部服務。
零廣告與追蹤 沒有追蹤代碼與干擾廣告，提供純粹沉浸的練唱體驗。
目前個人測試版 目前不設定付費牆；正式發布與服務條件尚未決定。

常見問題

支援中心與使用指南

快速搜尋或選擇分類查看詳細解答

如何開始使用「調唱」？需要註冊帳號嗎？
完全不需要註冊。在 Chrome 擴充功能商店安裝後，開啟任何 YouTube 或 Spotify 分頁，點擊工具列圖示開啟側邊欄，即可即時移調、變速或提取伴奏。
面板顯示「尚未找到可播放的歌曲」該如何排除？
請確認當前分頁的影片或音樂已按下播放（瀏覽器需要在媒體輸出時才能獲取音訊串流），隨後點擊面板上的「重新偵測」即可。若為本機檔案，可直接點擊「播放本機檔案」開啟 MP3/WAV。
如何儲存與管理多個 A-B 循環片段？
在播放時點擊「設 A」標記起點、「設 B」標記終點，接著點選「存為片段」並命名。同一首歌可儲存多個片段，點擊清單中的任一片段即可秒速跳轉並啟用該循環。
Vocal Reducer 人聲消減的運作原理？
調唱採用 Web Audio 的中置／側邊訊號處理降低常見的置中人聲；效果依歌曲混音而異，並非完整 AI 分軌，也不保證完全保留 Bass 或鼓。
如何使用 BPM 測速與節拍器？
跟著歌曲拍點連續點擊「TAP 測速」按鈕，或播放節奏清楚的段落使用「自動偵測」。結果可再手動微調；4/4 拍視覺脈衝燈與節拍聲可作為練唱輔助。
