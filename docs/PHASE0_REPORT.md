## 尚需使用者判斷

自動測試無法替代以下體驗：

- 真實人聲在 ±2、±5、±7 Key 時是否自然。
- 改 Key 的瞬間是否覺得有爆音、抖動或不舒服。
- 0.75× 時歌聲與伴奏的質感是否可接受。
- A、B 按鈕、數值密度與播放控制是否直覺。
- 長時間跟唱時，29 ms 的基礎延遲是否有主觀影響。

只要回報「你做了什麼、你以為會發生什麼、實際感覺如何」即可，不需要提供 console 或技術資訊。
