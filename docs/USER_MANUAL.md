# Karaoke Kaiju 0.1.0 公開測試版使用手冊

Karaoke Kaiju 是 Chrome 桌面版的 YouTube 練唱側邊工具。0.1.0 只開放已完成自動驗收的核心功能；研究功能不會出現在公開建置。

## 安裝

1. 執行 `pnpm install && pnpm run build`。
2. 開啟 `chrome://extensions`，啟用「開發人員模式」。
3. 選擇「載入未封裝項目」，指定專案的 `dist/` 資料夾。
4. 建議把 Karaoke Kaiju 固定在 Chrome 工具列。

## 開始練唱

1. 開啟 YouTube 或 YouTube Music 的歌曲分頁並播放。
2. 點一次工具列上的 Karaoke Kaiju 圖示。Chrome 規定分頁音訊擷取必須由使用者動作啟動，因此第一次使用每個分頁時不可省略這一步。
3. 側邊面板顯示歌曲名稱後即可調整 Key、Fine Pitch、Speed 與 A–B。

若面板顯示「尚未找到可播放媒體」，請確認目前分頁是一般 `https://` 網頁、歌曲已開始播放，並重新整理 YouTube 分頁後再點一次圖示。`chrome://` 等 Chrome 內部頁面不能擷取音訊。

## 核心控制

- **Key**：每按一次移動一個半音，範圍為 `−12` 至 `+12`。速度不會跟著改變。
- **Fine Pitch**：以 cents 微調音高，適合非 440 Hz 錄音或合唱校準。
- **Speed**：在 `0.25×` 至 `4.0×` 間調整播放速度，音高維持原 Key。
- **A–B**：先在歌曲目前位置設定 A，再設定 B，開啟循環即可重複練習。也可保存多個片段或設定逐階速度與重複次數。
- **播放列**：播放／暫停、前後跳轉、上一首與下一首。

設定頁可以切換亮／暗主題、按鍵大小、四種語言、跳轉秒數、自然人聲品質、Key 顯示範圍與快捷鍵。

## 歌單與連續播放

1. 在「歌單」建立一個練唱清單。
2. 保持歌曲分頁開啟，加入目前歌曲。Karaoke Kaiju 會一併記住 Key、cents、速度與 A–B。
3. 從歌單點歌會在原本的練唱分頁切換，不另開新視窗。
4. 可選擇依序播放或單曲循環；歌曲結束後依清單自動處理下一首。

開啟「Google 帳號與 Chrome Sync」後，歌單與歌詞會使用 Chrome 內建同步。Chrome Sync 的容量由 Chrome 管理；若資料接近配額，請減少大型歌詞紀錄或先關閉同步，資料仍會保留在本機。

## 歌詞

- 支援匯入 LRC、Enhanced LRC、SRT、WebVTT 與 TXT。
- 可調整整體偏移、單句起訖、字體、透明度、位置、底部歌詞欄高度與下一句提前量。
- 點擊歌詞句子可跳到對應時間；打拍模式可跟著歌曲逐句建立時間點。
- 校正後可匯出 LRC、SRT 或 VTT。
- 影片上以雙行方式提前顯示下一句；普通 LRC 以句內時間估算顏色進度，Enhanced LRC 才能提供較精細的逐字進度。

匯入歌詞前，請確認你有權使用該內容。本專案不內建、抓取或散布商業歌曲歌詞。

## 個人資料與清除

- 歌單、最近播放、歌詞與偏好預設位於 Chrome 擴充功能儲存空間。
- 可在設定頁清除最近紀錄或重設偏好，也可逐一刪除歌單與歌詞。
- 移除擴充功能會由 Chrome 清除本機擴充功能資料。
- 本公開版不要求外部 AI 或 Google Drive API 權限。
