## 1. 快速入門與支援平台

### 1.1 支援音樂串流平台
目前以 **YouTube / YouTube Music** 與一般 HTML5 media 作為主要驗收平台；Spotify、Apple Music、SoundCloud、Deezer、Tidal、Bilibili、Vimeo 的頁面辨識仍屬實驗性，可能受平台 DRM、權限與網站改版影響。另支援本機 MP3、WAV、FLAC、M4A、OGG 檔案。

### 1.2 開始第一次練唱
1. 開啟上述任一平台的音樂分頁（或播放本機音檔）。
2. 點擊瀏覽器工具列上的 **「調唱 🎵」** 圖示，側邊面板（Side Panel）將自動滑出並連接媒體。
3. 點擊「開始練唱」或調整 Key，聲音即時套用最新設定！

## 2. 專業音訊 DSP 引擎

### 2.1 ±36 半音超廣域獨立移調與 Fine Pitch 微調
- **十二平均律移調**：在設定中可選擇 **`±6`、`±12`、`±24`、`±36` 半音**（跨三個八度），每格嚴格對應半音音程（C → C♯ → D），升降調絕不改變播放速度。
- **Fine Pitch 音高 cents 微調**：支援 **`−100` 至 `+100` cents** 微調（每 100 cents 為 1 半音），適配特殊樂器調律（可在設定中切換 A4 = 432 / 440 / 442 Hz）。
- **自然人聲共振峰修正**：採用 LPC 線性預測編碼追蹤共振峰，大幅減少升 Key 尖細感與降 Key 低沉感。

### 2.2 Varispeed 磁帶變速連動模式
- **原理**：模擬傳統黑膠唱盤與開卷磁帶的物理特性，將音高與速度以物理公式 $2^{\Delta\text{Key}/12}$ 嚴格連動。
- **取捨**：以物理連動換取即時反應，避免額外的時間拉伸；極端速度或音域仍可能出現音質偽影，請以耳朵選擇適合的模式。

### 2.3 Vocal Reducer 人聲消除／伴奏提取
- **立體聲中置降低**：以中置／側邊訊號處理降低混音中常見的置中人聲（$L - R$）；效果依歌曲混音而異。
- **重低音補償**：加入低頻補償以減少伴奏變薄，但不保證完整保留 Bass 或大鼓，也不是 AI 完整分軌。
- **快速預設**：支援「原音 0% / 人聲消減 50% / 伴奏提取 85% / 極限消除 100%」。

### 2.4 3 段 Equalizer 等化器
- **頻段**：低音 Low (100Hz)、中音 Mid (1kHz)、高音 High (8kHz) 獨立增益（$-12\text{dB} \sim +12\text{dB}$）。
- **快速預設**：原音 Flat、人聲增強（$-2/+4/+2\text{ dB}$）、重低音（$+6/0/-2\text{ dB}$）。

## 3. 循環片段 (Clips) 與階梯練習序列 (Sequences)

### 3.1 多段 Loop 片段 (Clips)
- 在歌曲播放時，點擊「設 A」標記起點、「設 B」標記終點。
- 點擊 **「存為片段」** 並輸入名稱（例如：「主歌高音」、「副歌假音轉音」、「吉他 Solo」）。
- 可以在同一首歌中保存多個循環片段；實際數量受瀏覽器儲存配額影響。

### 3.2 階梯式提速練習 (Practice Sequences)
- 針對困難樂句，可進行循序漸進練習：先以 0.75× 練習 2 次，自動切換至 0.9× 練習 2 次，最後恢復 1.0× 原速，大幅提升肌肉記憶與唱歌咬字穩定度。

## 4. BPM 節拍偵測與視覺節拍器 (Tap Tempo)

- **Tap Tempo 測速**：跟著歌曲節奏連續點擊「TAP 測速」按鈕，系統以滑動加權平均法即時計算歌曲精確 BPM。
- **4/4 拍視覺脈衝燈**：以高對比燈號配合歌曲速度閃爍 1-2-3-4 拍（第 1 拍重音指示），幫助練唱者掌握下歌點與律動。
- **節拍聲音輔助**：可自由開啟或靜音節拍器發聲。

## 5. 雙行 KTV 動態歌詞與工作台

### 5.1 瀏覽器底部獨立 1/3 歌詞欄
- 歌詞顯示於影片下方獨立欄位（預設佔 1/3 畫面，可自由拖曳調整高度）。
- 游標移到歌詞欄上方時會浮現懸停控制列，可一鍵切換視窗模式、調整字體大小與時間校正。

### 5.2 側邊欄「逐句點播即唱」
- 側邊面板歌詞清單中，點擊任何一句歌詞，影片立刻跳轉至該句開頭並開始播放。
- 採用專屬 Scoped Auto-Scroll 容器限縮平滑滾動，外層視窗畫面完全鎖定不受干擾。

### 5.3 歌詞簡繁中文一鍵轉換 (繁 ⇄ 簡)
- **逐句點播卡片一鍵切換**：在側邊欄「逐句點播即唱」標題右上角設有高識別度「繁體」與「简体」切換標籤，點擊直接將整首歌詞（包含每句文字與單字時間戳）秒速轉換為目標字體。
- **全局偏好設定**：在設定頁中可指定「歌詞繁簡偏好」（一律繁體中文 / 一律簡體中文 / 維持原始），載入歌曲時自動套用。
- **專屬快捷鍵支援**：可隨時透過 <kbd>Alt</kbd> + <kbd>T</kbd> 秒速在繁體與簡體之間切換。
- **本機離線辭典**：內建繁簡中文對照辭典，無需連網即可切換。

## 6. KTV 大螢幕同歡模式

- 支援 **「KTV 劇院級大螢幕模式 (ktv-stage)」**：
  - 電視大螢幕超大字體（`clamp(32px, 5.2vw, 80px)`）。
  - 高對比發光卡拉 OK 漸層推進。
  - 適用於客廳電視投影、智慧大螢幕與朋友歡聚同歡。

## 8. 常見問題與線上支援 (FAQ)

### Q1: 調唱需要付費或升級 Pro 嗎？
**A**: 目前個人測試版沒有付費牆；正式發布、託管與服務條件尚未決定。

### Q2: 為什麼面板顯示「尚未找到可播放的歌曲」？
**A**: 請確認影片或音樂已經在分頁中開始播放（瀏覽器安全機制需要在媒體有音訊輸出時方能建立捕獲串流），隨後點擊「重新偵測」即可。

### Q3: 歌單與歌詞會被上傳到外部伺服器嗎？
**A**: 歌單與歌詞預設保存於瀏覽器本機；若您主動開啟 Chrome Sync，會由 Chrome 同步至您登入的 Google Chrome 帳戶。核心移調、變速與 BPM 在本機處理；若使用 AI 歌詞，只有在您明確同意後才會把音訊直接送往 Groq。
