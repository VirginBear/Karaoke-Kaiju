# Karaoke Kaiju 0.1.0 介面忠實度驗收

## 公開視覺基準

- 品牌名稱固定為 `Karaoke Kaiju`。
- 正式圖示來源為 `public/brand/karaoke-kaiju-app-icon.svg` 與 `public/brand/karaoke-kaiju-mark.svg`。
- 官網必須使用 `website/assets/` 內完全相同的品牌主檔。
- Chrome 圖示使用 `public/icons/` 的 16、32、48、128 px RGBA PNG。
- 顏色以 Apple 系統灰階、系統藍與單一暖色點綴為主；不使用漸層、厚重陰影或多套互相競爭的配色。
- 亮色、暗色、繁中、English、日本語、简体中文都必須實際操作，不只檢查靜態文字。

舊版概念稿與實作截圖屬本機設計歷史，已由 `.gitignore` 排除，不參與公開原始碼、建置或發布包。

## 側邊面板

- 390–420 px 寬度下不可水平捲動。
- Header 品牌、歌曲狀態與設定按鈕必須在單行內清楚辨識。
- Key、Fine Pitch、Speed、A–B 與播放控制具有一致的卡片、按鈕、焦點與 disabled 狀態。
- 公開建置只顯示已驗收模組；設定、歌詞與練唱頁不得出現研究功能入口。
- Key 的單位與十二平均律說明必須明確，`−12` 到 `+12` 不得被內容裁切。
- 大按鍵模式不能造成控制列重疊；精簡模式仍需維持可點擊範圍。
- Bottom Navigation 固定為練唱、最近、歌單、歌詞四項。

## 歌詞介面

- 雙行歌詞以白色為底、系統藍顯示進度，下一句需提前出現。
- 底部 Dock 高度可調且不應讓 YouTube 控制列無法操作。
- 影片內 Overlay 以 Shadow DOM 隔離，不能污染網站 CSS。
- 字體大小、透明度、垂直位置與提前量調整後立即反映。
- 逐句列表的自動捲動只作用於歌詞容器，不得拖動整個側邊面板。

## 官網

- 桌面 1536 × 1024 與行動 390 × 844 都要檢查首屏、互動 Demo、進度區、隱私區與 CTA。
- 所有 GitHub、使用手冊與隱私連結在 GitHub Pages 部署後仍可開啟。
- 語言與主題切換需保存偏好；四語文案不可宣傳公開版未開放的功能。
- 互動 Key 限制 ±12、速度限制 25%–200%，重設與循環按鈕狀態一致。

## 自動與手動驗收

`pnpm run check` 會驗證品牌主檔一致、圖示尺寸、四語名稱、版本、公開權限與 Chrome E2E 介面。發布前仍需人工確認：

1. 官網桌面／行動亮暗主題。
2. 側邊面板 390、420、600 px 三種寬度。
3. 四種語言的設定頁與歌詞頁。
4. 鍵盤焦點、螢幕閱讀器標籤與色彩對比。
5. 實際 YouTube／YouTube Music 的載入、切歌與歌詞覆蓋。
