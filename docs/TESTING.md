# 測試與載入方式

## 自動驗證（版本 0.0.12）

```bash
pnpm install
pnpm run check
```

`check` 依序執行：

1. TypeScript 型別檢查。
2. 音高倍率與時間格式單元測試。
3. Chrome MV3 正式建置。
4. 440 Hz 離線 DSP 精準度分析。
5. 在 Chrome for Testing 真正載入未封裝擴充功能，測試媒體偵測、tab capture、移調品質、同一 tab 切歌、preset 自動套用、自動下一首、單曲循環、Chrome Sync storage 與雙行歌詞覆蓋層。

測試用封裝會放在一次性暫存目錄，加入 localhost host permission 與 Chromium 測試 allowlist；正式 `dist/manifest.json` 仍只使用 `activeTab`，不會取得永久全網站讀取權限。

### YouTube 相容性測試

```bash
DIAOCHANG_SMOKE_URL='https://www.youtube.com/watch?v=d9IxdwEFk1c&list=RDd9IxdwEFk1c&start_radio=1' pnpm run test:extension
```

### 10 分鐘穩定性測試

```bash
DIAOCHANG_SOAK_SECONDS=600 pnpm run test:extension
```

## 載入日常使用的 Chrome

1. 先執行 `pnpm run build`。
2. 在 Chrome 開啟 `chrome://extensions`。
3. 開啟右上角「開發人員模式」。
4. 按「載入未封裝項目」。
5. 選擇本專案的 `dist/` 資料夾。
6. 如果你仍安裝 `0.0.4` 或更舊且 Chrome 顯示成不同 extension ID，請先移除舊版，再重新選擇本專案的 `dist/` 載入；之後可直接按重新載入。
7. 確認版本是 `0.0.12`。若 Chrome 顯示 Google 帳號資訊權限與 YouTube 網站權限，請允許；網站權限只包含 YouTube／YouTube Music。Groq 與 Google Drive API 網站權限只會在你主動使用對應功能時另外詢問。
8. 重新整理 YouTube 分頁，開始播放歌曲，再從工具列或拼圖選單點一次「調唱」。
9. 側邊面板應自動開啟並顯示「音訊處理中」。歌單切歌期間不需要再點圖示。

如果媒體偵測失敗，新版會區分「無法連接目前分頁」與「頁面已連接，等待媒體」。如果媒體已找到、但 Chrome 還沒有授權擷取音訊，面板會明確請你回到目前 YouTube 分頁點一次「調唱」圖示。

## 0.0.12 Google Drive `appDataFolder` 同步任務

1. 普通執行 `pnpm run build`，確認 `dist/manifest.json` 不包含 `oauth2`，設定頁顯示「開發者設定尚未完成」，按鈕不可誤報成功。
2. 在 Google Cloud 建立與固定 extension ID 對應的 Chrome Extension OAuth Client，使用 `DIAOCHANG_GOOGLE_OAUTH_CLIENT_ID='…apps.googleusercontent.com' pnpm run build` 重新建置。
3. 確認 `dist/manifest.json` 只包含 `https://www.googleapis.com/auth/drive.appdata` OAuth scope，不含一般 Drive 全磁碟範圍。
4. 到「設定 → Google Drive 大容量同步」按「授權並同步到我的 Drive」；允許提示後，確認顯示已連動與最後同步時間。
5. 在本機新增歌單與歌詞，等候自動同步；於另一台使用同一 Google 帳號及同版擴充功能的電腦連動，確認較新的歌單與歌詞分別保留。
6. 拒絕權限、離線與 Drive API 403 時，確認 UI 顯示真實錯誤且本機資料仍存在。
7. 停止 Drive 自動同步後，確認本機仍可使用；停用動作不會自動刪除 Drive 備份。
8. 按「刪除我的 Drive 備份」並確認後，驗證隱藏同步檔已刪除、自動同步關閉，但本機歌單與歌詞仍存在。

## 0.0.11 BPM 自動偵測任務

1. 開啟 YouTube、YouTube Music 或本機音訊，播放節奏清楚的歌曲。
2. 從目前分頁點一次「調唱」圖示，確認面板顯示「音訊處理中」。
3. 在「BPM 節奏與節拍器」按「自動偵測」；系統會擷取約 8 秒的節奏包絡，不會改變播放輸出。
4. 確認完成後顯示 BPM 與信心度，並可使用 TAP 或 `＋／−` 微調。
5. 改用靜音、短音訊或未啟動音訊測試，確認顯示下一步提示而不是假成功。
6. 把自動偵測結果與 TAP 測速、歌曲標示 BPM 比較，將誤差記在 `docs/DEVELOPMENT_LOG.md`。

## 0.0.11 階梯式 A–B 練習序列任務

1. 開啟可播放的 YouTube／YouTube Music 或本機音訊，點一次「調唱」並設定有效的 A、B 點。
2. 在「A–B 段落循環」展開「編輯階梯」；確認預設有 `0.75× × 2`、`0.90× × 2`、`1.00× × 1` 三階。
3. 修改任一階的速度（範圍 `0.25×`～`4.0×`）與次數（`1`～`20`），按「開始階梯練習」。
4. 確認第一階立即套用，並看到「第 1/N 階」進度。每次 A–B 從 B 回到 A 時，重複次數應遞增；達到該階次數後應切換下一階速度。
5. 最後一階完成後，確認階梯練習顯示完成，播放速度恢復啟動前的速度。練習中按「停止階梯」也應恢復原速。
6. 清除 A–B 或設定無效段落時，開始按鈕應停用並顯示需要先設定 A–B 的提示。
7. 先跑 `pnpm run check`，確認 `practice-sequence` 單元測試、型別檢查、正式建置與 extension smoke test 都通過；再於真實歌曲上記錄速度切換是否準時。

目前階段的切換依側邊面板定期取得媒體時間狀態判斷 B→A 邊界；極短 A–B 片段仍需在真實網站上做額外手感與漏偵測驗證。

## 0.0.11 YouTube／YouTube Music AI 歌詞任務

1. 在 YouTube 或 `music.youtube.com` 播放歌曲，從該歌曲分頁點一次 Chrome 工具列的「調唱」，確認顯示「音訊處理中」。
2. 進入「歌詞 → AI 產生動態時間碼」，輸入自己的 Groq API Key 並勾選音訊傳送同意。Key 沒有內建值，輸入後只會保存於本機擴充功能儲存空間；可按「清除已保存 Key」移除。
3. 按「從目前分頁產生動態歌詞」。歌曲會暫時以原速從頭播放並即時錄製；請讓歌曲與側邊面板保持開啟。
4. 等候時間約等於歌曲長度，之後還會有數秒 AI 上傳／對時時間。完成後應顯示已儲存句數，影片出現動態歌詞。
5. 確認原本速度、A–B、播放位置與播放／暫停狀態已恢復。也可在錄製中按「取消分頁錄音」檢查取消流程。
6. 如果按鈕停用，先回歌曲分頁再點一次「調唱」；只開著側邊面板並不代表 Chrome 已授權分頁音訊。

## 0.0.8《花香》歌詞顯示任務

1. 打開 `https://www.youtube.com/watch?v=-ZRrhoFBM4s`，播放後點一次「調唱」。
2. 進入底部「歌詞」，點「《花香》LRC 參考頁」，在該頁取得 `.lrc` 後回到面板選取檔案。
3. 按「解析並儲存到目前歌曲」；確認影片下三分之一出現兩句歌詞，當前句與下一句分別位於左上、右下。
4. 播放時確認白字上的藍色進度由左向右前進；Enhanced LRC 應依逐字時間前進，一般 LRC 則在每句時間範圍內平滑估算。
5. 依序使用 `−0.5`、`−0.1`、`+0.1`、`+0.5` 微調，確認顯示值與影片歌詞立即更新；「重設」應回到 `0.0 s`。
6. 在同一張覆蓋設定卡調整字體、歌詞框透明度與上下位置；確認影片上的覆蓋層同步變化。
7. 使用歌詞頁上方的播放／暫停、前後跳轉、設 A、設 B、循環與清除，確認不必切回練唱頁。
8. 在歌詞頁按「連動這個 Google 帳號」，確認顯示 Chrome 帳號、已連動與同步用量。這是 Chrome Sync，不會建立一般 Google Drive 檔案，也不需要專案自己的雲端。
9. 重新整理同一首 YouTube，確認已存歌詞、offset、字體、透明度與位置自動恢復；URL 即使含 `list` 參數也應匹配同一首歌。
10. 在另一台登入相同 Google／Chrome Sync 帳號的電腦安裝同一版，確認同一首歌的歌詞與顯示設定恢復。
11. 本機音訊仍可作為第二條 AI 路徑；若曾把 Key 暴露在程式碼、截圖或聊天記錄，請先到 Groq 撤銷並重新建立。

## 0.0.6 基礎功能回歸任務

不需要回報技術細節，只要照直覺完成下列工作，描述哪裡卡住或不舒服：

1. 點「調唱」圖示進入「音訊處理中」後，依序使用 Key `0`、`+1`、`+2`；確認聽到的是半音逐格上升，而不是歌曲變快。
2. 到「設定 → 移調品質」比較「標準」與「自然人聲」，特別留意主唱是否變尖細或低沉。
3. 把速度改成 0.75×，再改回 1.0×。
4. 在一句歌詞開頭按「設 A」，結尾按「設 B」，啟用循環。
5. 建立至少包含兩首歌的歌單，點第一首；確認仍使用原本 YouTube tab，且 Key／速度自動套用。
6. 選「依序播放」，把第一首拖到結尾，確認自動切到第二首；再選「單曲循環」確認歌曲從頭重唱。
7. 到設定展開「Google 帳號與 Chrome 同步」，按「連動這個 Google 帳號」，確認顯示 email 與「已連動」。
8. 在另一台登入相同 Google／Chrome Sync 帳號的電腦安裝同一版擴充功能，確認歌單出現。
9. 在設定依序切換繁中、English、日本語、简体中文，確認練唱、最近、歌單與設定文字都同步切換。
10. 播放一首歌後打開「最近」，確認歌曲、縮圖、Key 與速度出現；按播放應使用原本 YouTube tab，按加入歌單後能在目標歌單看到它。
11. 關閉 Fine Pitch 模組再回練唱頁，確認卡片消失；重新開啟後恢復。測試 Space、←／→、↑／↓ 快捷鍵。
12. 在設定依序點精簡／大，確認按鈕高度與間距立即明顯改變。

## 目前邊界

- 「歌單」及選擇同步的歌詞／時間／顯示設定已支援 Chrome Google Sync；Drive 大容量同步、排序、備註與匯出尚未實作。
- 「最近」刻意只存在本機；需跨電腦的歌曲請加入已開啟 Chrome Sync 的歌單。
- 歌詞採本機優先；開啟個人同步後會進入同一個 Chrome Sync 配額。尚未提供 Drive 大容量版本或逐句手動打拍編輯器。
- 一般 LRC 只有逐句時間碼，因此藍色進度是句內線性估算；Enhanced LRC 或 Groq word timestamps 才能做到較精準的逐字推進。
- Groq 是選用外部服務；擴充功能不保存 API Key，也不會在使用者按下分頁 AI 並同意前錄製或上傳音訊。
- 目前分頁 AI 採「即時播放並錄製」，不是下載 YouTube 檔案；產生一首四分鐘歌曲約需四分鐘錄音時間。最長單次錄製 15 分鐘，送出前限制 25 MB。
- 目前沒有 Equalizer 或人聲降低；設定列的「後續階段」不是可操作功能。
- 速度與 A–B 依賴網站的 HTML5 媒體元素；不同串流網站仍要逐站驗證。
- 音訊只在本機分頁、offscreen document 與喇叭之間流動，不上傳到專案伺服器。
