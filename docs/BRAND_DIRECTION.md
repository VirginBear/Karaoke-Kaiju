# Karaoke Kaiju 品牌方向（概念待確認）

- 文件狀態：概念提案，尚未套用到正式擴充功能

- 目前產品版本：0.0.12

## 1. 命名建議

### 推薦：Karaoke Kaiju

保留「唱歌怪獸」的角色核心，同時使用 `Karaoke` 清楚說明產品場景。`Kaiju` 比一般的 `Monster` 更有角色性，也能自然連接繁體中文、英文、日文與簡體中文市場。

建議品牌一律使用英文主名稱 `Karaoke Kaiju`，不要在不同語言改動商標字樣；各語言只在產品描述與標語中補充解釋：

- 繁體中文：Karaoke Kaiju｜找到你的 Key，唱出你的歌。
- English: Karaoke Kaiju | Find your key. Own the song.
- 日本語：Karaoke Kaiju｜自分のキーで、もっと自由に歌おう。
- 简体中文：Karaoke Kaiju｜找到适合你的 Key，唱出你的歌。

### 不採用：Karaoke Monster

Chrome Web Store 已有完全同名、同樣服務 YouTube／音樂網站並提供歌詞、人聲降低與 EQ 的擴充功能。直接使用會造成搜尋、辨識與上架混淆。

這只是初步公開名稱查核，不是商標法律意見。正式上架前仍需查詢主要發布地區的商標與網域。

## 2. 品牌角色

角色是「正在表演的友善怪獸歌手」，不是單獨一支麥克風。

- 怪獸是第一視覺焦點，麥克風只負責說明正在唱歌。
- 個性：有勇氣、喜歡唱歌、鼓勵練習；不兇惡、不幼兒化。
- 剪影特徵：向後的角、張口唱歌、短尾巴／聲波曲線、小型手持麥克風。
- 禁止模仿 Godzilla 或任何既有怪獸角色輪廓。

## 3. 視覺系統

延續目前產品的 macOS／iOS 乾淨介面，不加入新的多色品牌系統。

- 主墨色：`#111827`
- 強調色：`#0A84FF`
- 亮色背景：`#F5F5F7`、`#FFFFFF`
- 暗色背景：`#0B0B0D`、`#1C1C1E`
- 字體：系統字體堆疊（SF Pro、PingFang TC、Noto Sans TC、Helvetica Neue）
- 圓角、陰影與分隔線沿用現有產品 token，品牌不另外建立厚重裝飾。

## 4. 預先定義的驗收標靶

正式套用品牌前，必須先滿足以下條件：

1. 圖示在 16、32、48、128 px 均能辨識「怪獸正在唱歌」。
2. 16 px 圖示不可依賴眼睛、牙齒、手指或麥克風網格等小細節。
3. 圖示只使用深墨色與系統藍；亮、暗背景對比都需清楚。
4. 擴充功能 Header、Manifest、四語 locale、設定頁、README 與官網共用同一英文品牌名稱。
5. 網站使用同一圖示、色票、字體與元件語言，不另創第二套風格。
6. 網站功能必須標示「已可用／實驗中／規劃中」，不得顯示尚不存在的正式商店安裝連結。
7. 320 × 900、420 × 900 側邊欄，以及 390 px、768 px、1440 px 官網 viewport 不可水平溢出。
8. 正式改名後執行 `pnpm run check`，結果必須全部 PASS。

## 5. 網站資訊架構

1. Hero：`找到你的 Key，唱出你的歌。`，搭配實際側邊欄控制畫面。
2. 練唱流程：找 Key、放慢、A–B、雙行歌詞。
3. 開發狀態：已可用、實驗中、規劃中。
4. 創作者初衷：原 Key 不合、反覆拉時間軸、特殊版本只存在網路上的痛點。
5. AI 與隱私：AI 協助開發；核心音訊本機優先；外部 AI 需明確同意。
6. 開源與回饋：GitHub、使用手冊、隱私說明；清楚標示尚未正式上架。
